# Lista de exercícios — Seção 2

<sub>📚 [Documentação](../README.md) › [Seção 2 · Introdução à linguagem Java](./README.md) › Lista de exercícios</sub>

## História e plataforma

1. Explique qual problema de portabilidade motivou o projeto que deu origem a Java.
2. Quem foi James Gosling e qual foi seu papel no desenvolvimento da linguagem?
3. Qual era o nome original da linguagem e para que tipo de equipamento ela foi projetada?
4. Por que a Internet se tornou um destino adequado para as ideias de Oak?
5. Explique por que é incompleto afirmar que Linux, sozinho, causou a crise da Sun.
6. Em que anos a Oracle anunciou o acordo e concluiu a aquisição da Sun?
7. Diferencie Java como linguagem de Java como plataforma.
8. Diferencie Java SE, Java ME e Jakarta EE, antigo Java EE.
9. Explique a relação entre código-fonte, bytecode e JVM.
10. Diferencie JDK, JRE e JVM.

## Ambiente e execução

11. No terminal, verifique as versões com `java --version` e `javac --version`. Explique por que os dois comandos existem.
12. Crie, compile e execute um programa que mostre seu nome. Depois reproduza o processo com o material fechado.
13. Execute o mesmo programa como arquivo-fonte e explique a diferença entre essa forma e a compilação explícita com `javac`.
14. Compare a declaração clássica de `main` com a sintaxe simplificada apresentada para Java 25, sem usar conceitos ainda não estudados para explicar detalhes internos.
