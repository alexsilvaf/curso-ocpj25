Bloco 1

Introdução aos arrays

Um objeto com tamanho fixo e elementos do mesmo tipo.

Declarar e criar

A referência e o objeto array são coisas diferentes

int[] numeros;
numeros = new int[5];

int[] outros = new int[3];
O tamanho é definido na criação e não muda depois.

Posições

Índices válidos vão de zero a length - 1

10

índice 0

20

índice 1

30

índice 2

40

índice 3

Índice negativo ou igual a length causa ArrayIndexOutOfBoundsException.

Forma abreviada

Valores podem criar e preencher o array

int[] numeros = {10, 20, 30, 40};
String[] nomes = {"Ana", "Bia"};

numeros.length vale 4.

length é campo, sem parênteses.

Um inicializador isolado exige new int[] { ... }.

Bloco 2

Valores padrão e referências

Arrays são objetos; seus elementos também possuem estado inicial.

Elementos

Todo elemento recebe o valor padrão do tipo

TipoValor inicial
int[]0
double[]0.0
boolean[]false
char[]'\u0000'
Product[]null

Mesmo objeto

Atribuir a referência não copia o array

int[] a = {1, 2, 3};
int[] b = a;
b[0] = 99;
System.out.println(a[0]); // 99
a e b alcançam o mesmo objeto array no heap.

Array de referências

Criar o array não cria os objetos dos elementos

Product[] products = new Product[3];
// três elementos null

products[0] = new Product("TV", 900.0);
products[1] = new Product("Phone", 500.0);
A referência do array e as referências guardadas em seus elementos são independentes.

Bloco 3

Percorrendo arrays

for com índice ou for-each com elemento.

Percurso indexado

Use o índice quando a posição importa

for (int i = 0; i < numeros.length; i++) {
    System.out.println(i + " -> " + numeros[i]);
}
O limite exclusivo combina naturalmente com índices de 0 a length - 1.

Percurso pelos valores

for-each entrega uma cópia de cada elemento

int[] numeros = {10, 20, 30};

for (int numero : numeros) {
    System.out.println(numero);
}
Alterar numero não substitui o elemento do array.

Qual percurso usar

A necessidade de posição orienta a escolha

for tradicional

índice, alteração de posição, percurso parcial ou reverso

for-each

ler todos os elementos do início ao fim

Bloco 4

Arrays multidimensionais e rótulos

Um array pode guardar referências para outros arrays.

Duas dimensões

Uma matriz regular possui linhas com o mesmo tamanho

int[][] matriz = new int[2][3];
System.out.println(matriz.length);    // 2 linhas
System.out.println(matriz[0].length); // 3 colunas
Cada matriz[i] é uma referência para outro array.

Jagged array

Linhas podem ter tamanhos diferentes ou estar nulas

int[][] dados = new int[3][];
dados[0] = new int[2];
dados[1] = new int[5];
// dados[2] continua null
dados[2].length causa NullPointerException.

Saída de laços aninhados

Um rótulo permite controlar o laço externo

externo:
for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        if (matriz[i][j] == alvo) break externo;
    }
}
Sem rótulo, break encerra apenas o laço mais interno.

Bloco 5

A classe Arrays

Exibir, ordenar, buscar, preencher, comparar e copiar.

java.util.Arrays

Operações frequentes

import java.util.Arrays;

Arrays.toString(numeros);
Arrays.sort(numeros);
Arrays.fill(numeros, 7);
Arrays.equals(a, b);
Arrays.copyOf(numeros, 5);
Arrays.copyOfRange(numeros, 1, 3);

Busca binária

binarySearch pressupõe ordenação compatível

Arrays.sort(numeros);
int indice = Arrays.binarySearch(numeros, 30);

Encontrado: índice não negativo.

Ausente: valor negativo que codifica o ponto de inserção.

Bloco 6

Inferência local com var e variáveis sem nome

O tipo continua existindo, mesmo quando não é escrito.

Inferência

var recebe um tipo estático da expressão inicial

var numeros = new int[] {1, 2, 3}; // int[]
var nome = "Java";                 // String

// var valor;        // sem inicializador
// var nulo = null;  // tipo não inferível
Só pode aparecer em variáveis locais com inicializador, inclusive controles de laços.

Variável sem nome

_ declara um valor que será ignorado

for (String _ : nomes) {
    quantidade++;
}
A variável sem nome não pode ser lida. var infere um tipo; _ descarta um nome.

Bloco 7

Varargs e texto em arrays

Receber quantidade variável e transformar textos.

Parâmetro variável

Dentro do método, varargs é um array

static int somar(int... valores) {
    int total = 0;
    for (int valor : valores) total += valor;
    return total;
}

somar();
somar(1, 2, 3);
somar(new int[] {4, 5});

Declaração

Varargs precisa ser o último e só pode haver um

void registrar(String nome, int... notas)

válido

void registrar(int... notas, String nome)

inválido

Sobrecarga com array e varargs equivalentes produz a mesma assinatura.

String para array

split separa partes; toCharArray separa caracteres

String linha = "Ana,8.5,9.0";
String[] partes = linha.split(",");

char[] letras = "Java".toCharArray();
Agora essas operações aparecem porque arrays já foram apresentados.
