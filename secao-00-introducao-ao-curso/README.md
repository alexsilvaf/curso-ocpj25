# Seção 0 — Introdução ao curso

<sub>📚 [Documentação](../README.md) › Seção 0</sub>

## 🎯 Objetivos

Ao final desta seção, o aluno deverá ser capaz de:

- compreender a proposta e a progressão do curso;
- distinguir acompanhar uma explicação de conseguir reproduzir uma solução;
- estudar ativamente, prevendo resultados e escrevendo código sem copiar;
- usar os materiais, os slides e as listas de exercícios de cada seção;
- reconhecer quando revisar um pré-requisito antes de avançar;
- entender a relação entre aprender Java e se preparar para a OCP Java SE 25.

## 🧭 Percurso sugerido

1. Assista à apresentação antes de iniciar a trilha técnica.
2. Leia o material e defina como aplicará o ciclo de estudo.
3. Responda à lista sem consultar o material durante a primeira tentativa.
4. Siga para a Seção 1 e preserve a ordem das seções.

## 🧱 Como o curso está organizado

Cada seção concluída possui quatro partes complementares:

| Parte | Finalidade |
| --- | --- |
| apresentação | introduzir e organizar visualmente os conceitos |
| materiais | explicar o conteúdo de forma gradual e servir para consulta |
| exemplos guiados | mostrar o raciocínio e a construção de uma solução |
| lista de exercícios | exigir recuperação, previsão, escrita e explicação sem apoio imediato |

Não haverá uma sequência de “desafios” espalhados pelo conteúdo. As atividades de fixação e integração ficam reunidas na lista de exercícios da própria seção.
