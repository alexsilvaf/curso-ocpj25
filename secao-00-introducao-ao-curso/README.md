## 🎯 Objetivos

- compreender como o curso está organizado;
- reconhecer que assistir e copiar não bastam para aprender;
- usar a reprodução sem apoio e os exercícios para verificar o aprendizado.

Cada seção reúne:

- apresentação em slides;
- material de leitura;
- exemplos;
- lista de exercícios.

Os conteúdos seguem uma ordem gradual. Evite pular seções, pois cada uma considera os conhecimentos apresentados anteriormente.
