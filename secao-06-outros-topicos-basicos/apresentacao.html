Bloco 1

Restrições e convenções para nomes

O compilador impõe regras; a comunidade adota convenções.

Identificadores

O que pode e o que não pode formar um nome

Pode conter

  • letras;
  • algarismos depois do início;
  • _ dentro de nomes maiores;
  • $, embora seja desaconselhado.

Não pode

  • começar com algarismo;
  • ser palavra reservada;
  • ser apenas _;
  • conter espaço, hífen ou sinais.

Compilação

Nomes válidos e inválidos

Compilam

int idade = 20;
int nota2 = 8;
int _indice = 0;
int valor$temporario = 10;
×

Não compilam

// int 2nota = 8;
// int valor-total = 5;
// int class = 1;
// int _ = 3;

Case-sensitive

Maiúsculas e minúsculas distinguem nomes

int total = 10;
int Total = 20;

System.out.println(total); // 10
System.out.println(Total); // 20

Válido, mas confuso

São variáveis diferentes, embora distingui-las apenas pela capitalização dificulte a leitura.

true, false e null também não podem ser identificadores.

Convenções

O formato antecipa a função do nome

Operadores bitwise

Operações aplicadas à representação binária dos inteiros.

Base 2

O prefixo 0b identifica um literal binário

0b1100

12 em decimal

0b1010

10 em decimal

int a = 0b1100;
int b = 0b1010;

Bit a bit

&, | e ^ comparam posições correspondentes

aba & ba | ba ^ b
00000
01011
10011
11110

12 e 10

Três operações, três resultados

  1100
& 1010
  ----
  1000

8

  1100
| 1010
  ----
  1110

14

  1100
^ 1010
  ----
  0110

6

Complemento

~ inverte todos os bits

int x = 5;
System.out.println(~x); // -6

Relação útil: ~x == -x - 1.

Um int possui 32 bits, inclusive os usados para o sinal.

Deslocamentos

Esquerda, direita com sinal e direita com zeros

OperadorEfeito
<<desloca à esquerda, preenchendo zeros à direita
>>desloca à direita, preservando o sinal
>>>desloca à direita, preenchendo zeros à esquerda
12 << 1 vale 24; 12 >> 1 vale 6. Para negativos, >> e >>> diferem.

Também com boolean

& e | avaliam os dois operandos

Sem curto-circuito

false & (x++ > 0)

x é incrementado.

×

Com curto-circuito

false && (x++ > 0)

x não muda.

Precedência: deslocamentos → & → ^ → |. Use parênteses quando misturar grupos.

Bloco 3

Funções interessantes para String

Consultar, comparar e transformar textos.

Posições

Índices começam em zero

J

índice 0

a

índice 1

v

índice 2

a

índice 3

Para "Java", length() vale 4 e o último índice é length() - 1, ou 3.

Extraindo partes

O início entra; o fim não entra

String texto = "programacao";

texto.substring(3);    // "gramacao"
texto.substring(0, 4); // "prog"
substring(0, 4) usa os índices 0, 1, 2 e 3.

Buscando conteúdo

Presença, posição, início e fim

String email = "aluno@exemplo.com";

email.contains("@");          // true
email.startsWith("aluno");   // true
email.endsWith(".com");      // true
email.indexOf('@');              // 5
email.indexOf("inexistente"); // -1

Conteúdo

Compare textos com equals

String resposta = "sim";

resposta.equals("sim");           // true
resposta.equals("SIM");           // false
resposta.equalsIgnoreCase("SIM"); // true

Regra prática

== não é adequado para comparar conteúdo de String. Referências serão explicadas depois dos objetos.

Produzindo outro texto

Transformações frequentes

String original = "  Curso Java  ";

original.toUpperCase();            // "  CURSO JAVA  "
original.toLowerCase();            // "  curso java  "
original.strip();                  // "Curso Java"
original.replace("Java", "JDK"); // "  Curso JDK  "
"".isEmpty();                     // true
"   ".isBlank();                  // true

String é imutável

O método não altera o texto existente

String nome = "  Ana  ";
nome.strip();
System.out.println(nome);
Ainda contém espaços.
→
String nome = "  Ana  ";
nome = nome.strip();
System.out.println(nome);
Agora imprime Ana.

String e repetição

Percorra apenas índices válidos

String palavra = "Java";

for (int i = 0; i < palavra.length(); i++) {
    System.out.println(palavra.charAt(i));
}
Arrays, split() e toCharArray() ficam para a seção de arrays.

Bloco 5

Métodos: declaração e chamada

Dar nome a uma tarefa e executá-la quando necessário.

Do cálculo repetido

Uma operação pode receber um nome

double media1 = (7.0 + 8.0) / 2.0;
double media2 = (5.5 + 9.0) / 2.0;
→
static double calcularMedia(
        double a, double b) {
    return (a + b) / 2.0;
}

Declaração

Cada trecho define uma parte do contrato

static double calcularMedia(double primeira, double segunda) {
    return (primeira + segunda) / 2.0;
}
TrechoFunção
staticpermite a chamada pelo main nesta etapa
doubletipo devolvido
calcularMedianome do método
parâmetrosvalores recebidos, com tipo e nome
returnencerra e devolve o resultado

Definir e executar

Argumentos fornecem valores aos parâmetros

Declaração

static double calcularMedia(
        double primeira,
        double segunda) { ... }

Chamada

double resultado =
    calcularMedia(7.0, 8.0);

Programa completo

A execução sai do main e volta com um valor

public class CalculadoraMedia {
  public static void main(String[] args) {
    double media = calcularMedia(7.0, 8.0);
    System.out.println(media);
  }

  static double calcularMedia(double a, double b) {
    return (a + b) / 2.0;
  }
}
main chama
↓
método calcula 7,5
↓
return devolve

Método sem valor

void representa uma ação

static void mostrarLinha() {
    System.out.println("----------------");
}

mostrarLinha();

Não produz valor

// não compila
String linha = mostrarLinha();

Todos os caminhos

Um método não void precisa cumprir o tipo prometido

Não compila

static int sinal(int n) {
  if (n > 0) {
    return 1;
  }
}
→

Completo

static int sinal(int n) {
  if (n > 0) {
    return 1;
  }
  return -1;
}

Nesta etapa

O método fica na classe, mas fora de outro método

  • Pode aparecer antes ou depois do main.
  • Não pode ser declarado dentro de main.
  • Os exemplos usam static para permitir chamada direta.
  • Métodos de instância e membros de classe serão explicados na Seção 7.

Bloco 6

Parâmetros, retorno e passagem de valores

O parâmetro recebe uma cópia do valor fornecido.

Primitivo por valor

Alterar o parâmetro não altera a variável do chamador

int numero = 10;
dobrarLocalmente(numero);
System.out.println(numero); // 10

static void dobrarLocalmente(int valor) {
    valor *= 2;
    System.out.println(valor); // 20
}

numero

10
no chamador

valor

10 → 20
cópia local

Devolver e guardar

O retorno leva o cálculo ao chamador

static int dobro(int valor) {
    return valor * 2;
}
→
int numero = 10;
numero = dobro(numero);
System.out.println(numero); // 20

String por valor

Atribuir ao parâmetro local não substitui a variável original

static void normalizarLocalmente(String texto) {
  texto = texto.strip().toUpperCase();
}

normalizarLocalmente(nome);
// nome não muda
→
static String normalizar(String texto) {
  return texto.strip().toUpperCase();
}

nome = normalizar(nome);
// resultado guardado

Retorno antecipado

return encerra o método naquele caminho

static String classificar(int nota) {
    if (nota < 0 || nota > 10) return "invalida";
    if (nota >= 7) return "aprovado";
    return "reprovado";
}
Depois que um return executa, nenhuma instrução posterior daquele caminho é alcançada.

Escopo e composição

O chamador recebe somente o valor devolvido

Escopo local

Parâmetros e variáveis locais deixam de existir fora do método.

Composição

dobro(quadrado(3)) é lido de dentro para fora: 3 → 9 → 18.

Métodos coordenam texto, decisões, laços e operadores.

main

contemJava

Um if protege charAt quando o texto normalizado está vazio.

String + for + if

Contar vogais sem arrays

static int contarVogais(String texto) {
  int quantidade = 0;
  String minusculo = texto.toLowerCase();
  for (int i = 0; i < minusculo.length(); i++) {
    char c = minusculo.charAt(i);
    if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
      quantidade++;
    }
  }
  return quantidade;
}

Bits + método

Cada bit pode representar uma permissão

int leitura = 0b0001;
int escrita = 0b0010;
int exclusao = 0b0100;

int usuario = leitura | escrita;
usuario |= exclusao;
static boolean temPermissao(
    int conjunto, int mascara) {
  return (conjunto & mascara) != 0;
}
| liga bits; & verifica o bit indicado pela máscara.

Pontos de prova

Identificadores e operadores bitwise

  • Primeiro caractere não pode ser algarismo.
  • Reservadas e literais especiais não são nomes.
  • _ sozinho é reservado.
  • Convenção não interfere na compilação.
  • &, | e ^ aceitam inteiros e booleanos.
  • ~ inverte todos os bits.
  • >> preserva sinal; >>> insere zeros.
  • & e | avaliam os dois lados.

Pontos de prova

String e métodos

  • Índices começam em zero.
  • Fim de substring é exclusivo.
  • indexOf devolve -1.
  • String é imutável.
  • Parâmetros têm tipo e nome.
  • void não produz valor.
  • Todo caminho cumpre o retorno prometido.
  • Java passa argumentos por valor.
