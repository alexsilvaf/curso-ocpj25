## 📂 Organização

- Cada diretório `secao-XX` representa uma seção do curso.
- O `README.md` de cada seção reúne objetivos, conteúdos e um percurso sugerido sem estimativa de duração.
- Os arquivos `A1`, `A2`, `A3` e seguintes são o próprio material didático utilizado durante a aula.
- Toda seção possui uma apresentação em `apresentacao.html` e uma lista independente em `lista-de-exercicios.md` quando seu desenvolvimento é concluído.
- Diagramas e imagens ficam no mesmo diretório do documento que os utiliza.
- As listas de exercícios fazem parte do próprio curso e são mantidas neste repositório. Atividades avaliativas podem ser publicadas separadamente na plataforma do curso.

## ✍️ Convenções

- Novas seções devem seguir o padrão `secao-XX-nome-da-secao`.
- Os materiais devem seguir o padrão `AX - Título da aula.md`.
- As apresentações devem usar o nome `apresentacao.html` e as listas devem usar `lista-de-exercicios.md`.
- As apresentações são apoio visual para videoaulas: devem ser expositivas e não devem conter perguntas clicáveis, dinâmicas de turma ou blocos de exercícios.
- Cada comando de avanço deve abrir o slide seguinte; o conteúdo de um slide não deve exigir cliques adicionais para ser exibido.
- Exercícios ficam concentrados na lista da seção. Os materiais podem conter exemplos guiados e perguntas breves de verificação, mas não blocos de “desafios”.
- Os links para imagens e diagramas devem usar caminhos relativos.

## 🏅 Cobertura da OCP Java SE 25

Esta seção acompanha a cobertura do exame **Oracle Certified Professional, Java SE 25 Developer (1Z0-831)**.

O objetivo é manter um mapa claro entre o conteúdo já ensinado, os assuntos ainda parciais e os tópicos que serão abordados nas próximas seções do curso. Um assunto retirado de uma seção por razões didáticas não deve ser interpretado como conteúdo eliminado do curso.

### 🚦 Regra de acompanhamento

Cada assunto pode estar em um destes estados:

| Estado | Significado |
| :---: | --- |
| ✅ **apresentado** | o curso já ensinou os fundamentos necessários em aula |
| 📝 **preparado** | o material da seção está pronto, mas ainda não foi apresentado em aula |
| 🟡 **parcial** | uma base já foi ensinada, mas ainda falta conteúdo cobrado pela certificação |
| 🗓️ **planejado** | depende de uma seção futura |
| 🔁 **revisão final** | conteúdo apresentado que ainda receberá questões integradas no nível da prova |

### 🏁 Critério para declarar cobertura completa

O curso só poderá afirmar que cobre toda a OCPJ25 quando:

1. todos os domínios acima tiverem material preparado;
2. os recursos finalizados do Java 25 cobrados pelo exame estiverem mapeados;
3. cada seção tiver exercícios de leitura, compilação e previsão de saída;
4. houver questões que combinem conteúdos de diferentes seções;
5. houver revisão integrada e simulados no nível da certificação;
6. a matriz for conferida novamente contra os objetivos oficiais vigentes do exame;
7. nenhum conteúdo do objetivo oficial permanecer sem material ou destino definido.
